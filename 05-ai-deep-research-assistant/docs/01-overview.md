# 01. Overview

Deep Research Assistant is a Next.js application that turns a user question into a structured, cited research report. Instead of behaving like a simple chatbot, it works more like a small research agent: it plans the work, gathers evidence from the web, tracks sources, and synthesizes a final markdown report.

## What the app does

- Accepts a research question from the user
- Splits the task into focused subtopics
- Uses web search tools to gather evidence
- Deduplicates sources and tracks citations
- Streams progress updates while the report is being built
- Displays a final report with inline references

## Who this project is for

This project is useful for developers who want to learn how to build an AI-powered research workflow with:

- streaming UI updates
- structured planning and execution
- tool-using models
- source tracking and report generation

## Product experience

The app is designed as a research workspace. A user asks a question, watches the plan take shape, sees the system search and read sources, and then receives a polished report rather than a conversational answer.
